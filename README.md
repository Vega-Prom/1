# ВЕГА-Пром — сайт завода

Готовый статический сайт для GitHub Pages.

## Что внутри
- каталог сухих строительных смесей;
- карточки характеристик;
- раздел автоклавного газоблока;
- таблица размеров и цен;
- калькулятор газоблоков;
- история компании;
- контакты и карта;
- форма заказа, которая открывает WhatsApp.

## Публикация
Загрузите все файлы и папку `assets` в корень GitHub-репозитория.
В Settings → Pages выберите:
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

## Важно
Перед публичным запуском подтвердите актуальные цены, телефон отдела продаж и юридические формулировки.
После получения постоянного URL добавьте его в Google Search Console и создайте sitemap.xml под фактический адрес сайта.
